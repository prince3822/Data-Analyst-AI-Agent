# AI Data Analysis Agent using n8n
An AI-powered Data Analysis Agent built using n8n that enables users to analyze Google Sheets through natural language. The workflow integrates OpenAI, Google Sheets, and Gmail APIs to generate business insights and automatically send professional HTML reports.

## Features

- Natural language data analysis
- Google Sheets integration
- AI-powered insights using OpenAI
- HTML email report generation
- Gmail integration
- Conversation memory
- Automated workflow using n8n
